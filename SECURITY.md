# Security

Please report security problems privately, not in a public issue or pull request:
use **Report a vulnerability** on the repository's Security tab
(<https://github.com/irl-commons/irl-commons/security/advisories/new>).

This covers, for example:

- a weakness in the workflows, the checks or the npm publishing path;
- a way to get unreviewed changes into `main` or a release;
- credentials, tokens or personal data that ended up in the repository or its history.

Wrong or outdated data is not a security problem. Open an issue or a pull request
for it, as described in [CONTRIBUTING.md](CONTRIBUTING.md).

You'll get an answer from a steward. Nothing here is a bug bounty, and the project
can't pay for reports.
