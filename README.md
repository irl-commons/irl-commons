# irl-commons

Open data for IRL streaming, curated by hand. Part of it is primary data, written and checked here. The rest is directories: entries that point to what others publish, with facts about each.

## What's in it

**Primary data**

- **Words:** IRL streaming terms, explained in simple language.
- **Answers:** quick checks for common problems, from camera to platform.
- **Plans:** mobile carriers and their data plans. Empty for now.

**Directories**

- **Services:** apps, relays, receivers, hosted services, hardware and docs. Each entry says what it is and gives its official links and support channels.
- **Guides:** links to public tutorials, with the products they cover.
- **Standards:** formats and protocols such as SRT and SRTLA. Each entry says who makes it, how open it is, and which products use it.

Each entry has a public source and the date it was last checked. The data is incomplete. This is v0, so the format can still change.

IRL Commons lists products without ranking them. Being listed is not a recommendation. No advertising, no paid placement, no affiliate links.

## Where to start

**Streamers and helpers:** read it on [howtoirl.org](https://howtoirl.org). Something wrong or missing? Use "Suggest an edit" on the page.

**Industry, educators and everyone else:** something wrong, missing or out of date? [Suggest a new entry](https://github.com/irl-commons/irl-commons/issues/new?template=new-entry.yml) or [fix an entry](https://github.com/irl-commons/irl-commons/issues/new?template=edit-entry.yml). Is it about your own product? Use the [edit request from the maker](https://github.com/irl-commons/irl-commons/issues/new?template=maker-edit-request.yml).

**Developers and makers:** to use the data in your app, site or bot, start with [Getting started](docs/getting-started.md). [data/README](data/README.md) explains each file, and [CONTRIBUTING](CONTRIBUTING.md) explains how to send changes.

No GitHub account? Write to hello@irlcommons.org or ask on [Discord](https://discord.gg/KChVwU6fjk). Questions and ideas: [Discussions](https://github.com/irl-commons/irl-commons/discussions).
